# Future Product Vision

## One-sentence description

BestNative + Hermes Ops Kit + Hermes Agent will become a private-first AI SRE Runbook Platform: a controlled SRE workflow system where AI can diagnose, propose, execute only after approval, verify, audit, and feed lessons back into runbooks.

## What it is not

It is not just an AI chatbot for operations.
It is not a dangerous Web kubectl.
It is not a SaaS-first AIOps dashboard.
It is not a copy of one private environment.

## What it is

A local/private-first SRE workflow operating system built from three layers:

```text
Local Hermes   = real operational copilot and execution loop
Hermes Ops Kit = sanitized contracts, runbooks, schemas, safety rules and templates
BestNative     = Web/API control plane for assets, inspection history, approval and audit
```

## Core user workflow

```text
Add environment
→ generate env-map candidate
→ human review
→ run inspection
→ display inspection history
→ map abnormal checks to runbooks
→ ask Hermes for diagnosis
→ generate operation plan if change is needed
→ approval request
→ controlled execution
→ post-change verification
→ audit timeline
→ incident review
→ sanitized lessons flow back into Ops Kit
```

## Product value

- Turns implicit SRE experience into reusable runbooks.
- Gives AI stable facts before it reasons.
- Keeps high-risk actions behind approval and audit.
- Makes inspections and incidents trendable instead of one-off chat logs.
- Preserves private environment data locally while allowing sanitized templates to be shared.

## Target positioning

```text
Private-first AI SRE Runbook Platform for Kubernetes and middleware operations.
```

Longer description:

```text
A private-first AI SRE Runbook Platform that combines environment maps, inspection contracts, runbook metadata, approval/audit workflows, and Hermes Agent execution to turn operational knowledge into a safe, reusable, and auditable SRE workflow system.
```
